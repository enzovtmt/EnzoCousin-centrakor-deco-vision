## Ajouter les images

1. Ouvre une fiche produit officielle.
2. Clique sur la photo pour l'agrandir, si nécessaire.
3. Fais un clic droit sur la photo puis **Enregistrer l’image sous…**.
4. Enregistre-la dans ce dossier avec le nom indiqué dans le tableau.
5. Vérifie le format réel du fichier. Si l'image est enregistrée en `.webp` ou `.png`, conserve son extension et modifie aussi le chemin `image` correspondant dans `catalog.json`. Ne renomme pas simplement un fichier WebP en JPG.
6. Une fois les fichiers ajoutés, vérifie que les chemins sont de la forme `public/catalog-images/taho-blanche.jpg`, etc.

Les liens ci-dessus ouvrent les fiches produits officielles ; ils ne sont pas des liens directs vers les fichiers image. Utilise les visuels conformément aux droits et conditions du site, particulièrement si le prototype est publié.
